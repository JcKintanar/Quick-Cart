# Quick Cart

Quick Cart is a responsive **e-commerce web application** built with HTML, CSS, JavaScript, and Bootstrap.  
It is designed to provide users with a fast, clean, and user-friendly shopping experience.  
This project includes a **landing page, product listings, cart system, and checkout workflow**, making it a solid foundation for an online shopping platform.

## About the Project
Quick Cart was created to showcase a **modern e-commerce solution** that is responsive and easy to customize.  
The application is lightweight, easy to deploy, and serves as both a **portfolio project** and a **foundation for real-world online stores**.  

Key goals of this project:  
- Fast and mobile-friendly shopping experience  
- Simple cart and checkout flow  
- Easy to modify for different product categories  
- Scalable design using Bootstrap  

---

## Features
- **Landing Page** – Clean and professional homepage with call-to-action sections.  
- **Product Listings** – Display of items with images, prices, and descriptions.  
- **Shopping Cart** – Add, remove, and update product quantities.  
- **Checkout Page** – Summary of items and total price before purchase.  
- **Responsive Design** – Works seamlessly across desktop, tablet, and mobile devices.  
- **Social Media Integration** – Footer links to Facebook, Instagram, and Twitter.
